# Getting help

- **Something broken?** Open a [bug report](https://github.com/charles-forsyth/deep-research/issues/new?template=bug_report.yml).
  Please include `deep-research --version`, your OS and Python version, and the relevant part of
  `~/.config/deepresearch/logs/`. Remove your API key and any private content first.
- **An idea?** Open a [feature request](https://github.com/charles-forsyth/deep-research/issues/new?template=feature_request.yml).
- **A question about using it?** Check the [README](README.md), `deep-research <command> --help`,
  and existing [issues](https://github.com/charles-forsyth/deep-research/issues?q=is%3Aissue) first,
  then open an issue with the `question` label.
- **A security problem?** See [SECURITY.md](SECURITY.md). Please do not file it publicly.

Questions about the Gemini API itself (quotas, billing, model availability) are best directed to
[Google AI for Developers](https://ai.google.dev/gemini-api/docs).

This is a personal open-source project maintained on a best-effort basis.
